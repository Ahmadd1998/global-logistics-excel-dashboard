## 💻 Project 1: Logistics & Carrier Performance Dashboard (Python & Streamlit)

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-2C2D72?style=for-the-badge&logo=pandas&logoColor=white)

### 📌 Project Overview
Proyek ini adalah sebuah dashboard operasional data interaktif yang dikembangkan untuk menganalisis performa pengiriman lintas batas (*cross-border logistics*) dan evaluasi kinerja vendor ekspedisi. Dibangun menggunakan **Python** dan **Streamlit**, aplikasi ini mengolah ribuan log manifes pengiriman menjadi visualisasi data yang siap digunakan untuk pengambilan keputusan strategis.

### 🚀 Live Demo
👉 **[https://logistics-performance-id.streamlit.app/](https://logistics-performance-id.streamlit.app/)**

### 📊 Key Features
* **Customer Demographics:** Analisis profil dan data registrasi pelanggan.
* **Carrier Performance Tracking:** Evaluasi SLA vendor logistik, memonitor rata-rata keterlambatan (*delay*), dan jumlah klaim kerusakan barang.
* **Shipment Logs:** Pelacakan manifes pengiriman secara real-time.

### 🛠️ Data Pipeline & Workflow
1. **Raw Data:** Menggunakan dataset operasional kompleks dalam format `.xlsx`.
2. **Data Preparation:** Pembersihan data (*handling duplicates & missing values*) dan pemisahan dataset menggunakan Jupyter Notebook (`pandas`).
3. **Deployment:** Merancang antarmuka web interaktif menggunakan Streamlit Cloud.

## 📊 Project 2: Customer Acquisition & Logistics Operational Risk Dashboard (Tableau)

[![Tableau](https://img.shields.io/badge/Tableau-Public-E97627?style=for-the-badge&logo=tableau&logoColor=white)](https://public.tableau.com) 
[![Data Analytics](https://img.shields.io/badge/Analytics-Business%20Intelligence-blue?style=for-the-badge)](https://public.tableau.com)

### 📌 Project Overview
Proyek ini adalah sebuah dashboard operasional data interaktif yang dikembangkan menggunakan **Tableau Public** untuk menganalisis performa akuisisi pelanggan (*Customer Acquisition*) sekaligus mengevaluasi risiko operasional logistik lintas batas. Aplikasi ini mengubah data log operasional yang kompleks menjadi visualisasi analitis yang siap digunakan oleh pemangku kepentingan untuk pengambilan keputusan strategis.

### 🚀 Live Demo
👉 **[View Dashboard on Tableau Public](https://public.tableau.com/app/profile/ahmad.gozali.abbas/viz/CustomerAcquisitionPerformanceDashboard/LogisticsOperationalRiskDashboard#3)**

### 📊 Key Features
* **Customer Acquisition Performance:** Analisis metrik konversi, tren pendaftaran pelanggan, serta efisiensi performa akuisisi berdasarkan wilayah.
* **Logistics Operational Risk:** Pemetaan risiko pengiriman lintas batas, monitoring rata-rata keterlambatan (*delay*), dan identifikasi anomali performa vendor.
* **Interactive Filtering & Slicers:** Fitur interaktif untuk menyaring data regional secara real-time guna investigasi mendalam terhadap metrik bisnis.

### 🛠️ Data Pipeline & Workflow
1. **Raw Data:** Menggunakan dataset operasional kompleks berisi log akuisisi dan logistik global dalam format `.xlsx`.
2. **Data Modeling & Preparation:** Pembersihan data ringan, penataan relasi antar tabel (*data modeling*), serta pembuatan kalkulasi metrik bisnis langsung di dalam Tableau Environment.
3. **Dashboard Deployment:** Merancang antarmuka visual yang interaktif dan mempublikasikannya secara live via Tableau Public Cloud.
