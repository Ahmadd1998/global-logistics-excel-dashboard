## 💻 Project 1: Logistics & Carrier Performance Dashboard (Python & Streamlit)

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-2C2D72?style=for-the-badge&logo=pandas&logoColor=white)

### 📌 Project Overview
This project is an interactive data operations dashboard developed to analyze cross-border shipping performance and evaluate delivery vendor efficiency. Built using **Python** and **Streamlit**, the application processes thousands of shipping manifest logs into actionable data visualizations for strategic decision-making.

### 🚀 Live Demo
👉 **[https://logistics-performance-id.streamlit.app/](https://logistics-performance-id.streamlit.app/)**

### 📊 Key Features
* **Customer Demographics:** In-depth analysis of user profiles and customer registration data.
* **Carrier Performance Tracking:** Monitors logistics vendor SLA, tracks average delivery delays, and aggregates damaged goods claims.
* **Shipment Logs:** Provides real-time tracking and monitoring of shipping manifests.

### 🛠️ Data Pipeline & Workflow
1. **Raw Data:** Utilizes a complex operational logistics dataset in `.xlsx` format.
2. **Data Preparation:** Handles data cleansing (duplicates & missing values) and dataset segmentation using Jupyter Notebook (`pandas`).
3. **Deployment:** Designs and deploys the interactive web interface using Streamlit Cloud.

## 📊 Project 2: Customer Acquisition & Logistics Operational Risk Dashboard (Tableau)

[![Tableau](https://img.shields.io/badge/Tableau-Public-E97627?style=for-the-badge&logo=tableau&logoColor=white)](https://public.tableau.com) 
[![Data Analytics](https://img.shields.io/badge/Analytics-Business%20Intelligence-blue?style=for-the-badge)](https://public.tableau.com)

### 📌 Project Overview
This interactive operational dashboard was developed using **Tableau Public** to analyze customer acquisition performance while evaluating cross-border logistical risks. The application transforms complex operational log data into analytical visualizations, enabling stakeholders to make data-driven strategic decisions.

### 🚀 Live Demo
👉 **[View Dashboard on Tableau Public](https://public.tableau.com/app/profile/ahmad.gozali.abbas/viz/CustomerAcquisitionPerformanceDashboard/LogisticsOperationalRiskDashboard#3)**

### 📊 Key Features
* **Customer Acquisition Performance:** Analyzes conversion metrics, customer registration trends, and regional acquisition efficiencies.
* **Logistics Operational Risk:** Maps cross-border shipping risks, monitors average transit delays, and identifies delivery vendor anomalies.
* **Interactive Filtering & Slicers:** Empowers users to filter regional data logs in real-time for deep-dive business metric investigations.

### 🛠️ Data Pipeline & Workflow
1. **Raw Data:** Sources data from a complex operational dataset containing global acquisition and logistics logs in `.xlsx` format.
2. **Data Modeling & Preparation:** Conducts data cleansing, establishes table relationships (data modeling), and creates business metric calculations directly within the Tableau environment.
3. **Dashboard Deployment:** Designs the interactive visual interface and publishes it live via Tableau Public Cloud.
